# 月芽农场

农场为 1440×960，面积正好为原 960×720 的两倍。主屋保留在原坐标；移除固定田地、围栏、花槽、独立水井、池塘、长椅、路灯和其他人工布置。开局没有耕地，整片土地长有可清理的树木、石块、灌木和蕨草。保留门阶与镇口短石路，并为房门、房屋水源和镇口留出自然通路。

## 清理与自由开垦

- 复用现有法杖交互、动作动画、音效、背包和资源奖励。树木、石块需要多次采集，升级提高效率；杂草一次清除。
- 清理后植被、石块及其碰撞一起消失，土地释放后可开垦。房屋占地不可耕作，升级后的范围耕作跳过尚未清理的地块。
- 耕作网格覆盖整张地图内部区域（43×29 格，每格 32 像素），玩家自行决定农田位置与大小，没有预设田块轮廓。
- 清理进度、未完成的砍伐、农田和作物随存档保存；农场障碍不会每日刷新。野外采集仍保留原有每日刷新规则。
- 原有地块 ID 0–95 保留原世界坐标，新区域地块 ID 从 96 追加。旧存档作物保持原位，新生成的障碍不会覆盖已有农田。
- 房屋东侧 (366,276) 为房屋水源，补充现有法杖储水。独立水井和池塘不再存在。

房门 (270,276) 与出门落点 (270,258) 保留。农场东缘 (1432,364) 接小镇西口；镇口进入农场的落点为 (1398,364)。摄像机、边界碰撞、天气、房屋遮雨、昼夜、脚步声、地图预览和存档边界同步扩大。

## 种植

开发操作：选中法杖后互动键（默认 F）切换红蓝颜色，鼠标左键作业。红色清理树木、石块和杂草；蓝色面向近处地块依次翻土、播种、浇水和收获，在房屋水源处补水。蓝色法杖消耗背包里的香草种子，扩展作物使用种植页选定的作物种子；单独选种子仍只扣当前格的种子。操作说明仅保留在开发文档，玩家界面只显示名称、状态和结果。详情见 `Scenes/Equipment/README.md`。

初始 12 颗香草种子、24 单位储水。雨水会打湿所有已开垦土地，室内和夜间也生效；湿土上的作物进入次日时生长，香草累计 3 天成熟。收获、交易、背包容量、多种作物、季节和肥料规则沿用现有系统。

## 生成和验证

~~~powershell
python Art/Environment/Hearthwood/tools/build_farm.py
python Localization/build_catalog.py
python Scenes/Gameplay/run_verification.py farm
python Scenes/Gameplay/run_verification.py farm_capture
~~~

生成器只写入 Art/Environment/Hearthwood/，复用现有素材，不修改 MyArt/。farm_ground.png 是地面，farm_overview.png 是初始荒地总览，farm_layout.json 记录建筑、可清理资源和地图接缝。

farm_terrain.gd 统一地块坐标、稳定 ID 和占地判断；farm.gd 负责运行时地图和交互；loop_state.gd 保存清理、农田和作物状态。地图预览读取相同布局并隐藏已清除的障碍。

验证使用独立的设置和存档路径，覆盖真实输入砍树、清石、除草、碰撞移除、防止重复奖励、自由开垦、下雨、跨天生长、旧作物保留、扩大区域的保存恢复及房门和小镇真实行走。截图输出到 output/wild_farm/Verification/。
