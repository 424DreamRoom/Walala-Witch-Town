# 每日小镇委托

每日天气与料理偏好之外，系统会从四类轻量委托中轮换一项：林间来货、新芽入仓、灯下待客、潮声带回。委托只追踪当天新增的采集、收获、上菜或钓鱼行为，达成后立即发放金币并增加小镇声望。

委托数据由 `town_pulse.gd` 按天数确定，不使用随机数；进入次日时重置进度，存档时保存当前请求、进度和是否已领奖。旧存档缺少这些字段时根据天数补齐，因此不会改变已有主线章节或居民支线。

HUD 的小镇脉动卡只显示天气、料理偏好和当前委托进度。所有操作方法仍留在开发文档中，玩家界面只显示名称、数量、进度和结果。

验证：

```powershell
python Scenes/Gameplay/run_polish_regressions.py town_pulse
```
