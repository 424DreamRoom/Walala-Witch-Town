# 小女巫餐厅完整循环原型

## 启动与操作

直接打开项目 F5，或打开 `Scenes/LanternLane/lantern_lane.tscn` F6。主场景配置没有修改。场景运行时组装，编辑器空画布正常。

主角与六位客人已按截图的人物风格重绘为原生32×48像素，当前素材、四方向行走与进食动画的编辑源和校验记录见 `Art/Character/Storybook/README.md`。

室外已加入庭院、路灯、花坛、长椅、水井和小池塘等装饰，野外树木与人物共同按脚底Y排序；采集提示保持在树冠上方。资源与重建说明见 `Art/Environment/Hearthwood/README.md`。

```powershell
& 'C:\Program Files (x86)\Steam\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe' --path . --windowed --resolution 1280x720
```

- WASD / 方向键四方向移动；Shift 跑步；E 近距离互动（27 像素）。
- 小镇出生点北侧绿色路标：E 进入独立野外；东南侧橙色路标：E 进入餐厅。
- 出生点西侧第一间绿屋顶住宅：门前“家 E”路标按 E 进入小女巫之家；从室内底部入口走下台阶，按 E 回镇。家为 640×480 像素地图，家具参与碰撞和 Y 排序；在家时收起菜单、背包和操作提示，保留时间及声音设置。
- 野外走近采集点反复按 E；左下黄色出口 E 回小镇。
- 野外有6棵可砍树、2处矿点和1处可钓鱼池塘。走近出现交互提示后按 E 自动使用对应工具：每棵树砍3次获得木材3，每处矿点挖3次获得矿石2；挥动期间不能移动，连续按键不会叠加动作。
- 池塘位于野外右下，站在南岸按 E 抛竿，等待2–4秒；浮漂跳动、出现感叹号和“咬钩！E”时，在1.5秒内按 E 收竿获得鱼1。过早收竿或错过咬钩不扣池塘鱼数，每天最多钓3条。移动、Esc 或 R 可取消钓鱼。
- 木材、矿石与鱼在野外顶部同一行显示，和原食材背包分开记录，不占12格食材容量。已采集资源跨天保留，采伐进度、树桩、矿点及鱼数次日刷新。切换场景或结束白天会取消未完成动作。资源目前用于收集，未接入配方、建造或出售；沿用原型规则，关闭游戏后重新开始。
- 餐厅左上备料台前 E：加工背包全部原食材。右上料理台前点击右侧做菜按钮，等待 3 秒自动端起；走到订单匹配的客人座位按 E 上菜。
- 白天点右侧菜单按钮上下架（按下态表示上架）；夜间锁定。默认三道全上架。鼠标悬停显示配方说明。
- 右上按钮提前结束白天、结束营业、进入次日；无材料、空菜单也可以结束，不会卡死。
- 丢弃手中菜按钮可解困，不退原料。
- 1 晴 / 2 雨 / 3 雪；R 复位（小镇原出生点，野外/餐厅左下出口，家中底部出生点）；F3 原碰撞调试保留。没有改全局 InputMap。

## 精简界面

常驻键位说明、操作教学、经营规则、空座编号和重复耐心倒计时已删除。顶部显示天数、阶段、剩余时间、地点和金币；家与小镇不显示背包、菜单或烹饪侧栏，野外同一行显示食材背包与采集资源，餐厅显示库存与当前料理状态。

菜单仅在白天的餐厅显示；营业时走到料理台附近才出现做菜按钮；有手持菜时才显示丢弃按钮。配方留在按钮悬浮提示中。路标、采集点、备料台与出口文字仅在靠近时显示；顾客保留订单和耐心条。操作反馈显示 3.5 秒后自动隐藏，声音设置和阶段推进按钮仍可使用。

## 完整循环及明确规则

白天 **180 秒**（小镇、野外、餐厅共享计时）→ 夜晚 **120 秒** → 结算（等待按钮）→ 次日白天。时间到自动转换；白天结束自动回餐厅，避免玩家在野外错过营业。夜间仍可回镇，但野外关闭。

野外 9 个点，每点每日 2 份；3 种食材各 6 份。原食材背包容量 **12**；采空/满包不扣采集点。备料 1:1：蘑菇→切片菇，莓果→莓果酱，香草→香草料；厨房库存无容量上限。UI 分别显示背包与厨房库存。夜间也允许补加工已有背包，不自动替玩家加工。

| 菜品 | 厨房配方 | 收入 |
|---|---|---:|
| 蘑菇汤 | 切片菇2 | 12 |
| 莓果派 | 莓果酱2 | 14 |
| 香草炖菇 | 切片菇1 + 香草料1 | 18 |

菜单不要求现有库存，可预先选择。夜间每 6 秒尝试来一名客人，最多 3 座；立即落座，无入场动画。仅从已上架且当前有料的菜中按序点单；缺货不接新单，满座不覆盖客人。**不预留订单原料**：多个客人可能竞争最后一份，可让其超时或结束营业。既有订单不因缺货自动变更。

耐心 **25 秒**，条与剩余秒数可见；超时离店，不付款。只有在料理台附近才能开始做菜；每次开始扣配方一次，耗时 **3 秒**，最多一份料理或一份手持菜。料理期间可以移动；完成后自动端起（角色旁有占位盘子）。送错订单保留菜与客人，不扣钱、不加收入。送对立即清空座位并计入本晚收入。收入只在营业结束一次性入账。

结束营业时清空所有未服务客人（计入离店）、手持菜及未完成料理（计废弃，已扣材料不退）；次日**原食材、厨房原料、金币和菜单保留**，采集点全部刷新。结算不继续计时、角色暂停移动。无材料的一天可零收入结束，下一天重新采集。

## 架构与保护范围

- `loop_state.gd`：计时、采集、库存、菜单、配方、料理、订单/耐心、收入与结算；所有库存写入集中处理。
- `harvest_actions.gd`：砍伐/开采动作、按时间结算一次的命中、钓鱼阶段、取消和像素特效；`resource_node.gd`：资源碰撞、受击抖动、剩余进度、树桩/碎石切换。工具沿用小女巫原生32×48尺寸、脚底锚点和六个编辑层；60帧方向动作、PNG图层源和Aseprite兼容源在 `Art/Character/Storybook/WalalaTools/`，可用 `python Art/Character/Storybook/tools/build_tools.py` 重建。
- `game_loop.gd`：小镇入口、场景切换、按地点和操作显示的中文 UI、按键和空间交互检查。UI 使用项目内置的缝合像素字体 12px 简体中文比例版本，由 `ui_font.gd` 共享，全局主题也覆盖悬浮提示和新控件。字体来源与授权见 `Art/Fonts/FusionPixel/README.md`。
- `play_area.gd`：独立野外/餐厅 PNG 环境美术与静态碰撞、采集点、工作台、顾客、耐心条、菜盘绘制。地图资源在 `Art/Environment/Hearthwood/`。
- `Scenes/WitchHome/witch_home.tscn` / `witch_home.gd`：可从小镇进入的家；复用主角移动、镜头和游戏计时，室内不绘天气或播放雨声。
- `verify_loop.gd`：真实引擎循环集成验证；`run_verification.py`：有界等待自建 Godot 子进程并留日志，超时仅终止这个子进程；不仅检查退出码，也检查 FAIL/脚本错误/完整完成标记。
- LanternLane 加载新的环境美术并接入玩法控制器，常驻键位说明层已删除。独立地图切换时将非活动世界移出树，避免旧碰撞体残留；复用原小女巫纹理、动画、CharacterBody2D 与 move_and_slide。
- `--no-loop` 可单独探索旧小镇；原 `--lane-test` / capture 入口不接入玩法 UI，不覆盖旧测试截图。

## 真实验证

Godot 4.7.2，本机 Windows；日志在项目 `output/loop_headless.log`、`loop_gui.log`、`loop_lane.log`、`loop_weather.log`。截图 `Scenes/Gameplay/Verification/` 同时保存实际 SubViewport 与整个渲染窗口图，不是合成图。

```powershell
python Scenes/Gameplay/run_verification.py headless
python Scenes/Gameplay/run_verification.py gui
python Scenes/Gameplay/run_verification.py lane
python Scenes/Gameplay/run_verification.py weather
python Scenes/Gameplay/run_verification.py harvest
python Scenes/Gameplay/run_verification.py harvest_capture
```

- headless 与 Compatibility/OpenGL 窗口实跑两天：真实 physics 行走到路标→E采集→回镇→备料→鼠标菜单→鼠标提前结束→订单→走料理台→点击做菜→实际等3秒→行走到客人→E送餐→结算→次日刷新。每天收入12，累计24，进入第三天。
- 两天主要路径不注入库存或传送玩家；行走方向注入走原 `_physics_process` / `move_and_slide`。E 经 Input.parse_input_event，按钮点击从根窗口 push_input 经 SubViewportContainer 真实命中测试。
- 边界在同一个运行控制器上注入针对性状态：满包、采空、加工不可重复、远程做菜拒绝、重复做菜不重扣、缺货、三座满员、送错保留、丢菜、耐心超时、昼夜自动计时转换、营业末料理清理、库存结余、零材料跨日、结算收入不重复、切场景后雨雪/R/F3及碰撞。
- 最终 headless **93 项 PASS**，Compatibility/OpenGL 窗口 **121 项 PASS**（含28项截图保存），均完整完成、退出0、无FAIL/脚本错误。保存14组、28张真实截图。
- 原角色/小镇50项与天气16项回归通过。查看小镇、野外、备料、手持菜/订单、结算与满座窗口截图，中文库存与提示清晰可读。
- 首次测试暴露原视觉容器无命中尺寸导致按钮不响应，已在新增控制器补齐640×360尺寸。窗口截图等待帧信号曾在不绘制时超时，验证脚本改为主动真实 RenderingServer.force_draw，不能把超时算通过。
