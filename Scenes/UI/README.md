# 哗啦啦魔女镇 · 局内界面

界面使用 640×360 原生像素画布、Fusion Pixel 12 字体和项目的 Framewright Lite 木质主题。像素时钟、背包物品图标、打开的手记书页由 `hud_art.gd` 绘制；头像来自项目已有的原创居民动画。不使用参考游戏的截图或美术素材。

所有 UI 遵循根目录 `AGENTS.md` 的文案规范：不显示按键教学、快捷键后缀、鼠标操作说明或下一步操作指引。底部物品格按用户要求保留左上角键位角标。对话只保留剧情内容，任务只显示目标、地点和进度；场景文字显示对象名称和当前状态。按钮、按键设置中的键位及必要的结果和失败原因仍正常展示。操作方法仅写在开发文档中。

- 左上：缩小后的时间卡片显示天数、星期、游戏时刻、时段和天气，删除底部地点名称，时段文字留出内侧边距。时钟数字和指针每 30 个游戏分钟更新；白天为 06:00–18:00（现实 9 分钟），18:00 停钟等待玩家确定菜单并开业，营业为 18:00–22:00（现实 5 分钟）。结算固定显示 22:00，不再显示独立倒计时条。开业前餐厅侧栏显示菜单数量、营业时段、「食谱」和「开始营业」，空菜单禁用开业，营业时菜单锁定。
- 常驻界面显示左上时间卡片和底部物品格；顶部地图按钮、四季手记按钮以及季节／日期／金币状态文字已移除。金币在背包里查看，任务和季节日历在手记里查看。
- 底部：10 个物品格共用连续的木质底框和细分隔线，整栏为 268×32 原生像素，水平居中、贴齐画布下边缘，显示背包前 10 个真实槽位，背包容量保持不变。图标保持原生像素大小；数量右下角对齐，左上角显示 `1–9、0` 键位角标，对应数字键选中格子，金色边框与淡色底纹标出当前项。数字统一使用 `Art/Fonts/HudDigits8/digits8.tres` 原生8像素位图字体、最近邻采样和1像素深色阴影，不缩放12像素字体。角标与选框随道具栏设置和结算状态一同隐藏。开局选中第一格法杖；法杖、食材与材料共用背包格数。空格子可选中；点击栏位仍打开背包，扩容后继续保留物品位置。
- 餐厅：保留备料、菜单选择、烹饪、丢菜、营业结算操作；移除右侧厨房库存和本晚收入文字面板。
- `J` 打开手记，进行中 / 已完成筛选、详情和追踪；`B` 打开背包；`H` 打开巡灯员萤萝的对话，按当前章节提供目标、生活话题与主线交付；`M` 打开地图，点击区域或入口查看详图，再按 M / Esc 收起。地图显示玩家位置、农田、设施和出入口，详见 `Scenes/Map/README.md`。萤萝的世界形象与开场接入见 `Scenes/Campaign/GUIDE.md`。
- `Esc` 打开暂停菜单，提供继续游戏、手动保存、设置和返回主菜单；白天在家时另有「家具建造」，打开已有的制作与摆放面板。房屋扩建在榛木家具店柜台办理，详见 `Scenes/Building/README.md`。移除顶部营业按钮、右侧入口和任务追踪卡、底部标题与操作说明、底部菜单 / 自动存档状态 / 声音工具条。结算窗口保留「进入次日」按钮；自动存档继续运行，保存失败时临时显示原因。
- 对话：正文框为432×84原生像素，整体居中靠下；立绘卡片为88×104，人物保持比例显示为48×72。姓名框缩为110×26，长名字自动换行；三个选项合计占118×58区域，每项118×18、间隔2像素，右侧底部对齐，第四项向上增加一行。删除「回看」按钮。正文保留12号像素字体及自动换行。逐字显示，`E` / 空格显示整段或继续，鼠标选项或 W / S 与 Enter 确认，`L` 回看，`Esc` 关闭。
- 木箱：在家中建造和摆放，走近按 E 打开并暂停。左右两侧显示真实背包和箱子数量，选中物品后单个或批量存入、取出；E / B / Esc 或关闭按钮返回。工具存入后暂时不能使用，取出保留升级等级；满包时保留未取出的物品。详见 `Scenes/Storage/README.md`。
- 阅读对话、手记、背包或地图时暂停世界、营业时间和客人耐心，关闭后恢复。`Esc` 优先关闭当前窗口；采集中的 Esc 仍然立即取消动作。

选中状态记录在 `loop_state.gd` 的 `selected_hotbar_slot`，随进度存档；旧存档默认第一格。仅当前格中的法杖可用于砍伐、开采、钓鱼、翻地、浇水和补水；香草播种只消耗当前选中格中的种子，另一格的种子不会代扣。格子移动、清空后立即按其中的实际物品判定；切换格子取消工具动作。采集地上的食材、收获成熟作物、交易及餐厅加工沿用各自规则。扩展作物仍使用种植页选定的作物种子。

数字键 `1–9 / 0` 直接选择对应格子；鼠标滚轮向上选择前一格、向下选择后一格，在全部 10 格之间首尾循环，空格子也参与切换。滚轮复用数字键的选中高亮、切换音效与工具动作取消逻辑。

背包、对话、地图、暂停、建造、开场、转场、改键捕获和结算期间不响应数字键或滚轮选择，弹窗中的滚动仍由当前界面处理；修饰键组合、键盘长按重复、滚轮释放和横向滚动不触发选择。道具栏隐藏时保留数字键与滚轮选择能力。自定义操作占用了数字键时优先执行自定义操作。天气调试已迁至 `F6 / F7 / F8`，不再占用物品栏数字键。

专项验证：`python Scenes/UI/run_verification.py hotbar`；四语言实机截图：`python Scenes/UI/run_verification.py hotbar-capture`。检查选中格高亮、物品使用条件、选中堆叠消耗、动作取消、暂停与改键隔离、旧存档兼容和真实农耕输入；使用进程专属设置和存档，截图位于 `output/hotbar_selection/`。

四项入镇指引的累计进度在 `loop_state.gd` 的成功采集、备料、上菜、钓鱼事务中更新，跨日保留，写入六栏存档的 `state.journal`。旧版本缺少该可选字段的存档仍可载入，并从零记录新增指引；其他已存进度不变。

开局法杖由 `loop_state.gd` 记录，占一格背包，使用不会消耗，跨日保留并写入 `state.tools.wand`。旧工具合并为一把法杖并继承最高升级等级，详见 `Scenes/Equipment/README.md`。靠近树木、矿点或钓点按 E 使用法杖；农场面向田地按 E 翻地、种植、浇水或收获，井边或池塘边按 E 补水，详见 `Scenes/Farm/README.md`。上述操作方法仅保留于开发文档。

`start_dialogue(speaker, portrait_path, lines, choices)` 可用于后续居民剧情。每个 choice 是 `{text, action: Callable}`，不依赖向导演示内容。

## 描述富文本

对话正文、对话回看、任务描述和装备效果说明共用 `game_hud.gd` 的 `rich_label(source, rect, parent, color, font_size)`，使用原生 `RichTextLabel` 解析 BBCode。普通文本继续正常显示；按钮、标题和 tooltip 保持原有文字控件。

内容可使用 `[color=#247f78]关键词[/color]`、`[b]粗体[/b]`、`[i]斜体[/i]`、`[u]下划线[/u]`、`[s]删除线[/s]` 和 `[font_size=18]较大文字[/font_size]`，可嵌套。使用 `[lb]` / `[rb]` 显示字面方括号。粗体和斜体由同一 Fusion Pixel 字体派生，样式默认字号统一为 12；字号变大时需确认文本仍处于既有区域内。

示例：`欢迎来到[color=#247f78]哗啦啦魔女镇[/color]！`。向导对话的地点、资源，以及任务描述中的食材等关键词已采用青绿色强调。新增或修改带标签的原文时，同步维护 `Localization/messages.tsv` 的完整四语言句子，保留标签及颜色值，再运行 `python Localization/build_catalog.py`。翻译先于 BBCode 解析，禁止拆分翻译被强调的词组。生成器检查常用样式标签的闭合、嵌套及各语言一致性。

逐字显示使用 `get_total_character_count()` 统计解析后的文字；标签不占显示时间。手动显示整段、即时速度、末句选项和对话回看使用同样的可见文字计数。已显示完整的对话在语言切换后保持完整，正在逐字显示的段落按新语言重新开始；回看同步更新并保留样式。正文忽略鼠标和焦点，回看保留滚动。

动态效果使用 `[jump]跳动文字[/jump]` 和 `[sway]摇曳文字[/sway]`，可与颜色、粗体等标签嵌套，对话、回看、任务和装备说明均支持。`rich_text_motion.gd` 通过原生 `RichTextEffect` 做像素对齐位移，跳动默认高度 2 像素、每秒 1.8 次；晃动为平滑的左右摇曳，整个片段共用相位，保持字距和垂直基线，默认水平幅度 2 像素、每秒往返 1.2 次。不使用游戏的随机数序列。可设置 `[jump height=2 speed=1.8]…[/jump]`、`[sway strength=2 speed=1.2]…[/sway]`；高度限制为 0–4，摇曳幅度为 0–3，以保留像素字体的可读性。两种效果的 `speed` 均为每秒完整周期数，跳动速度上限为 6，摇曳速度上限为 4；幅度或速度为 0 时停止对应运动。文字标签及参数须在各语言中保持一致。

「设置 → 游戏」提供独立的「文字跳动」和「文字晃动」开关，默认开启，保存到设置文件 `[game] text_jump` / `text_sway`，主菜单和局内共用。「恢复本页」恢复开启，保留当前语言和其他分类设置。关闭某种效果时立即显示该范围的静态字形，颜色、字体样式、换行、逐字进度及回看内容保持原样；不重新解析文本。打开对话暂停世界时，文字动画继续播放。

专项验证：`python Scenes/UI/run_verification.py rich-text`；四语言截图：`python Scenes/UI/run_verification.py rich-text-capture`。覆盖嵌套样式、方括号、精确显示时长、手动与即时完成、仅含标签的段落、回看、语言切换、描述区域高度和暂停恢复，使用进程专属测试设置和存档。动态效果验证还覆盖独立开关、参数边界、当前逐字进度、设置保存与恢复默认；截图模式对比动画及静止帧，确认关闭后像素不变、暂停世界时文字仍可运动，输出 `text_motion_00.png` 至 `text_motion_23.png` 以及四语言游戏设置截图。

验证：`python Scenes/UI/run_verification.py`；截图：`python Scenes/UI/run_verification.py capture`。验证使用专用存档和设置文件，不读写玩家正式栏位。

## 设置面板

`settings_panel.gd` 在主菜单与局内暂停菜单共用。左侧分类、右侧对齐控件、底部恢复本页 / 鸣谢 / 返回；使用现有木框、纸张、像素字体和交互音效，不增加常驻 HUD。下拉菜单嵌入 640×360 画布，跟随整数像素缩放。

- 声音：按参考图排列全局音量、音乐、角色音效、环境音效、UI音效五条滑杆，右侧显示 0–100 数值。调至 0 静音，即时生效并自动保存。全局音量乘在各分类音量上；角色音效控制脚步及采集、加工、烹饪等动作，环境音效控制雨雪天气声，UI音效控制菜单反馈。恢复本页保留其他分类设置。
- 画面：全屏、三种窗口尺寸、垂直同步、30 / 60 / 120 / 不限帧率、画面亮度。亮度范围 -50～50，默认 0，滑杆中心为原始画面；即时预览并自动保存，恢复本页回到 0。全屏时禁用窗口尺寸。窗口尺寸仍使用整数缩放并保留周围留白。
- 游戏：简体中文 / English / 日本語 / 繁體中文语言切换、慢 / 标准 / 快 / 即时对话、默认跑步（Shift 切换步行）、道具栏显示、文字跳动、文字晃动。
- 按键：13 项操作的主按键与备用按键，点击后捕获新键；支持冲突交换、清除备用键和恢复默认，滚动列表跟随键盘焦点。Enter / Tab / Esc 保留用于界面操作。

选项即时生效并写入 `user://preferences.cfg`，独立于六个进度存档；重置只影响当前分类。局内设置保持世界暂停，返回设置上级仍处于暂停菜单。界面不添加解释性段落或保存提示。

画面亮度使用 `brightness.gdshader` 对 `SubViewportContainer` 的最终像素进行 gamma 调整；启动提示、主菜单与游戏场景均继承 `display/brightness`。0 不改动像素，负值调暗、正值调亮；黑色、白色和透明度保持原值，不改变昼夜控制器、地图灯光或像素采样。暂停时设置仍可立即更新，亮度调整不会反复切换窗口模式或分辨率。

亮度专项验证：`python Scenes/UI/run_verification.py brightness`；Compatibility 实际像素与四语言截图：`python Scenes/UI/run_verification.py brightness-capture`；Forward+ 实际像素验证：`python Scenes/UI/run_verification.py brightness-forward-capture`。使用进程专属临时设置与存档目录，覆盖真实鼠标/键盘输入、数值、保存、菜单重开、场景继承、暂停预览、昼夜光照保持、恢复默认，以及黑白像素保持；截图位于 `output/brightness/`。

语言切换立即更新界面、对话、任务、交易及动态数字文本，并跨重启保留；「恢复本页」保留当前语言。翻译维护与验证见 `Localization/README.md`。

按键映射即时生效并保存，界面不显示操作提示；移动保持等速斜走，跑步开关仍生效。局内改键期间保持暂停，Esc 取消捕获后留在设置页。输入实现与验证见 `Scenes/Input/README.md`。

布局参考：[Stardew Valley Options](https://stardewvalleywiki.com/Options) 的选项分组与控件类型，以及 [Planet Zoo Graphics Settings](https://interfaceingame.com/screenshots/planet-zoo-graphics-settings/) 的分类设置案例。现有游戏风格通过项目原有素材实现。
