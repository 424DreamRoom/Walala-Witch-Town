# 新版剧情与露辛达

当前运行主线为《明天晚点开门》，原稿与接入边界见 [游戏接入说明](../../Narrative/Rebuild_20261020/游戏接入说明.md)。十二章旧主线的验证脚本仅供历史参考，新流程使用 `run_rebuilt_story_verification.py`。

新存档：八段86秒分镜 → 码头玛伦 → 告别离开 → 农场门前与露辛达碰面 → 两人一起出发 → 食堂门外入场 → 屋内签约 → 第一天安顿与熟悉 → 回家休息 → 第二天准备营业。主角默认名为艾洛温，旧档自定义名字保留。分镜可略过，60句开场对白保留，开场暂停游戏计时。临时入场角色使用现有原生精灵，结束后清理。

第一天只安排自由熟悉住处和小镇，手记显示“初来乍到”，露辛达也只谈安顿和休息。食堂签约时就隐藏菜单、菜谱和营业入口，底层同时拒绝开业和交付营业章节。当天到傍晚仍可自由活动，不自动传送食堂或进入夜间营业。家里显示简洁的“休息”按钮，淡出后直接到第二天早晨，不生成零收入营业报告。第二天恢复普通备料、菜单和营业流程，仍需玩家确认开业。

2026年10月21日补充场景过渡：分镜与码头之间保留上一画面至完全淡出；码头结束后主角先向出口离开，再换到农场道路；农场见面时主角走向小屋、露辛达从右侧道路走来；谈完后两人沿路离开，下一镜先交代食堂门口，再从室内入口走到莫文和托宾面前。所有换场复用 `SceneTransition` 的0.25秒淡出、0.25秒淡入，角色定位与清理在全黑时完成。行走期间保持游戏计时暂停、原输入锁定；最终对白结束恢复正常活动。读档期间已有淡入淡出时，开场等待该转场完成后再接续，防止重入或丢失角色。

`rebuilt_story.py` 编译本目录外的11个对白原稿、英文/日文对照与繁体文本，替换运行表里的主线、开场、向导话题和相冲突的居民对白。正文535句包含开场60句和十章主线475句。姓名、头像、回看与四语言切换复用原 HUD。`场景索引.json` 的 `opening_segments` 显式划分三处对白，构建时校验连续完整覆盖。`开场分镜.json` 保存八镜头的四语言源文本与时长，影片按累计时间定位镜头，字幕与画面共同淡入淡出。

当前文风使用日常口语。2026年10月22日新增99句，另修正第一章中未承接上句的对账回应。重点讲清招租原因、前任店主离开与旧账、供货成本、灌溉与排洪取舍、月环机制和停机责任、主角过量接单的动机、退款与经营余款、安全停机、雨夜协作及最终续租。修改时先让角色回应上一句、说明实际原因，再表达情绪；避免用半句话、抽象比喻、刻意机锋或格言代替人物要说的事。同步检查分镜字幕、任务简介和向导话题，避免玩家在不同入口听到两种口吻。

露辛达白天在小镇入口附近（脚底约464,408）守灯。她不占居民好感、支线名额或餐厅顾客索引，共享脚底碰撞与Y排序。世界精灵使用原生32×32帧，保持整数像素格。欢迎段保留左行后上行的进场路径；离场、食堂门外与室内行走使用相同的原生方向动画，食堂签约后释放镜头和角色移动。

主线顺序、指标、数量、奖励和探索门槛见 [README](README.md#主线与解锁)。第八章按项消耗铁锭4、零件6、月晶4，其余目标为累计记录。支线仍然可选，主线不要求刷满好感。

`onboarding.gd` 在首日安顿期间显示回家休息的目标；第二天起把备料、菜单、首次上菜安排在第一章，把种植与湿润地块安排在第二章。它只推导已有状态，不增加奖励或完成门槛。目标与地点保留在手记，自由活动不增加教学浮窗；所有玩家文案不包含操作教学。

操作仅供开发和测试：沿用原移动、近距离互动、料理翻页与回看、菜单、烹饪、送餐、法杖与农田输入，没有增加输入映射。开场仍锁定世界移动和背包，但对话模式放行原翻页、回看和选项输入。可用游戏原有向导入口或手记完成当前章，已完成页可回顾。

保存字段：`story_version=2`；`opening_stage=0..3`；`pending_scene=-1`或已交付未读完的章节索引；`legacy_chapter=0..12`保存旧版解锁；`settling_in` 保存首日安顿状态，休息进入次日后清除。旧档缺少此字段时按 `false` 补齐，保留已有营业进度。章节交付记录奖励和挂起对白并保存；读完再清除挂起场景并保存。中断从本段开头恢复，不重复发奖或扣料。首日休息后另存第二天早晨的保存点，普通经营仍采用六小时自动保存。

旧版在游玩存档跳过新开场，新主线从第一章开始，保留金币、库存、田地、工具、好感、居民支线和原区域解锁。所有字段继续经过白名单和数值校验。剧情中的租金、船期与大订单是事件文本，没有新增自动扣租、限日失败或运输模拟。
