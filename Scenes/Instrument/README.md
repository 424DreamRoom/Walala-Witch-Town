# 家具乐器

钢琴是室内家具建造物，配方位于「工坊」分类，摆放后沿用家具碰撞与存档。靠近已摆放的钢琴时，场景互动会打开暂停式演奏面板。

面板固定为 3 行 × 7 列：每行对应一个自然音八度（C4–B4、C5–B5、C6–B6），按钮由左至右排列。按钮支持鼠标、当前映射的界面焦点导航与隐藏的 QWERTY 三行键位映射；玩家可在不改变输入设置的情况下使用任一方式演奏。按键映射属于开发实现，玩家界面只显示音符名称。

21 个钢琴单音采样位于 `Sounds/Walala/Instrument/`，由同目录的生成脚本用原创泛音包络生成。音频通过 `audio_manager.gd` 的效果声部播放，因此遵循音效音量和静音设置，并可在暂停的演奏界面继续发声。
