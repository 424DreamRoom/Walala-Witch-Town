# 家具建造

房地产魔女、餐厅长期租约与住宅室外占地扩建见 [PROPERTY.md](PROPERTY.md)。

白天可在农场或家中进行建造与布置。共 69 种配方、69 个独立图标，包含栅栏、床、座椅、桌台、柜架、灯具、地面、装饰、庭院和工坊。新游戏保留空屋与空收纳；农场房屋东侧坐标 (416,288) 有一座固定建造工作台，可制作更多工作台再摆到家中或农场。制作需要当前场景的工作台边缘 32 像素范围内，扣除背包中的木材、铁锭和矿石，产出进入跨场景共享的家具收纳；没有工作台时仍可摆放和整理已有成品。

建造图鉴每页 8 项，支持 10 类分类、名称筛选、分页、各项图标及材料持有数/需求数。配方标明室内、户外或两者皆可；完整清单见 `Art/Building/CATALOG.md`。界面、状态和 tooltip 只包含名称、条件、材料、结果与失败原因，不显示操作教学。

摆放预览吸附到 16 像素网格。鼠标定位并单击，或使用当前映射的移动键定位、互动键确认。绿色表示可摆放，红色表示被占用或阻塞。右键、Esc 或当前返回键取消。本模式暂停游戏时间与角色移动。

「整理房间」在农场与家中均可选中当前场景的建造物后移动或收回。移动确认前保留原位，取消不改变房间；收回恢复一件成品，不返还制作材料。出入口及玩家通往门口的道路受保护；家具具有真实碰撞，移动、收回后同步更新寻路碰撞矩形。室内可摆放范围、网格和寻路校验使用当前房屋等级的地板。

小镇西侧原花园住宅（门口坐标 200,636）为「榛木家具店」，柜台在白天提供「房屋扩建」。小空屋地板 192×128 原生像素，第一次扩建为 320×208，费用为 120 金币、30 木材、3 铁锭；第二次扩大为原先的 512×288，费用为 400 金币、80 木材、8 铁锭。费用不足或已达到最大面积不扣除资源。扩建只扩大房屋，不赠送家具；家具 ID、位置、收纳和箱内物品保持不变。

`house_catalog.gd` 定义等级、价格、地板、墙体、镜头边界和地图大小。`Art/Environment/Hearthwood/tools/build_empty_homes.py` 依据该几何生成三档空房的原生木墙、木地板和家具店椅子招牌，不改写旧房屋美术。扩建完成后再次回家立即应用新地板、墙体碰撞和镜头边界，地图同步展示实际大小与家具。

木箱需要 8 木材。摆放后走近按互动键（默认 E）打开，在箱子与背包间存取食材、资源、工具及香草种子。箱子有 12 格，每种物品最多 99 个，工具 1 件；装有物品时可移动，取空后才能收回。详见 `Scenes/Storage/README.md`。

房屋等级、家具收纳、唯一 ID、种类及位置属于每个独立存档。缺少房屋等级或家具字段的旧存档迁移为原先的大房间，保留原本家具、地毯、炼金台和厨房，不清空玩家进度。读取时拒绝非法等级、未知家具、重复 ID、负数库存、超出当前等级地板及重叠摆放。制作、整理与扩建结果在下一个游戏时钟六小时保存时刻，或手动、退出保存时写入，支持四种语言及自定义按键；界面只显示家具、按钮和状态，不显示操作教学。

房屋专项验证：`python Scenes/Building/run_verification.py housing`；实际画面与四语言服务截图：`python Scenes/Building/run_verification.py housing-capture`。覆盖小空屋碰撞、真实输入建造、门口可达、家具商店入口、两次精确扣费、材料不足、最高等级、关闭后的过期点击、家具与箱内物品保持、地图和磁盘存档回读。使用进程专属测试设置和存档，输出位于 `output/housing_progression/`。

旧存档的六种或七种家具收纳会补充缺少的新配方库存，新增值均为零。箱子内容与摆放 ID 一起保存，跨场景、跨日和重启保留；未知物品、非法数量、重复工具及附着在其他家具上的物品会被拒绝。

验证使用独立设置和存档，不修改玩家正式进度：

```powershell
python Scenes/Building/run_verification.py headless
python Scenes/Building/run_verification.py capture
```

`furniture_catalog.gd` 提供稳定配方与几何校验；`loop_state.gd` 负责库存事务和存档迁移；`furniture_builder.gd` 提供界面及布置会话；`witch_home.gd` 根据存档生成家具和碰撞。

## 农场建造与持久化

农场摆放使用 16 像素网格，地图完整范围可通过移动键带动建造镜头浏览；关闭时恢复进入会话前的镜头。房屋、水源、固定工作台、作物、未清理自然资源和门口至小镇的既有通道受保护。新建实体具有真实碰撞，地砖、地毯为地面层，栅门和拱门预留通行；地面可铺在家具下面。同一层的建造物不可重叠，布置不能把玩家封在围栏内，建造占用地块不能再耕作。最多 256 个已摆放建造物，单种成品库存上限 999。

农场木箱使用现有 12 格真实仓储，非空箱可移动、不能回收。灯具在家中保持柔和照明，在农场随黄昏亮起。其余床铺、柜架、花盆和工坊陈设属于可布置家具，不附加生产或跳过营业日的行为。家具和户外建造物使用同一个唯一 ID 序列；户外对象保存 `area=farm`，旧对象省略此字段时仍属于家中。读取会校验场地、边界、碰撞、作物和未清理资源。原有室内家具与扩建进度保留，地图同步展示室内外实际布置。
