# 区域地图

局内按 **M** 打开地图，M / Esc 或右上角关闭按钮收起。打开时暂停角色、时钟和营业；地图不覆盖背包、对话、暂停菜单或家具摆放窗口。结算阶段禁用地图。

全镇总览展示小镇、月芽农场、微光采集地和潮汐码头的连接关系。点击区域缩略图、建筑入口或右侧列表，查看九个区域的详图，包括家、餐厅、杂货店、铁匠铺和榛木家具店。点击地图切换查看目标区域，玩家继续留在原场景。

- 蓝点：当前玩家位置。室内玩家在全镇总览中显示于所在建筑入口，室内详图显示实际坐标。
- 金点：出入口、补水点、备料台、料理台和柜台。
- 绿点：农田和钓鱼点；采集地还显示剩余采集点。
- 农田显示已锄地、浇水及作物生长阶段；家中按当前房屋等级显示地板、边界与摆放的家具，扩建、移走或收纳后同步变化。新游戏不显示旧住宅的固定设施；旧存档保留原有住宅布局。

地图绘制采用“手绘城镇图”构造：总览以双色墨线连接小镇、农场、采集地和码头，在留白处加入指南针、叶脉和路线节点；详图保留原始像素地面与建筑，在小镇中心、农场耕作区、采集点和码头水岸叠加低对比度的区域构造线。每个区域缩略图和详图使用统一的纸张边框、四角压线与最近邻缩放，参考多洛可小镇的街区分区、东方夜雀食堂的暖色纸面层次和星露谷物语的路径/农田信息密度。装饰线只绘制在地图画布上，不写入原始素材，也不改变场景碰撞、入口坐标或交互。

`game_map.gd` 维护区域切换和界面，`map_canvas.gd` 从现有场景布局、地面与物件素材绘制地图，并读取当前游戏状态。地图不另存副本；建筑与出口采用对应区域的布局坐标。边缘物件裁剪在各自地图内，图像使用最近邻缩放。

地图支持项目四种语言，「设置 → 按键 → 区域地图」可修改主键和备用键，地图界面不显示键位或操作提示。旧配置的 M 已占用时保留原键并自动选用空闲功能键。

```powershell
python Scenes/Map/run_verification.py headless
python Scenes/Map/run_verification.py capture
```

验证使用独立设置文件且不启用玩家存档，覆盖实际鼠标和快捷键、区域与入口切换、坐标投影、暂停恢复、农田与家具同步、改键与旧配置迁移、四语言及其他模态窗口的输入保护。截图和日志写入 `Verification/`。
