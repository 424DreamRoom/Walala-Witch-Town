# 木箱与物品存取

暂停菜单已移除家具建造入口，目前不能从菜单新建木箱；已有存档中的木箱仍可使用。木箱配方消耗 **8 木材**。走近已摆放的箱子按当前互动键（默认 **F**）打开。

箱子在上、背包在下，使用独立方格。箱子有 12 格；背包随原有升级解锁 12 / 18 / 24 / 36 格，前 10 格同步到游戏快捷栏，其余格子在背包中管理。每格普通物品最多 99 个，工具每格 1 件，同一种物品可以分成多个独立堆叠。

左键拿起或放下整组，也可按住左键拖到另一个格子；不同物品可交换。同类堆叠最多合并到 99 个，其余继续拿在鼠标上。右键拿起一半（向上取整），拿着物品时右键放下 1 个。Shift＋点击在箱子与背包间快速转移，优先合并已有堆叠，放不下的留在原处；单独打开背包时在第一排与扩展格之间移动。

所有随身物品共用格子容量。采集、钓鱼、购买和收获检查实际可用格子，失败时不消耗金币、资源节点或成熟作物；熔炼可使用消耗材料后腾出的格子。工具存入后不再算随身携带，取出保留升级等级，法杖现有储水量也保留。金币、装备等级及厨房原料仍属于原有专门系统。

F / B / Esc 或右上关闭按钮收起箱子，B 单独打开背包。关闭时鼠标上的剩余物品自动放回库存；极端无空位时回退尚未完成的拿取事务。拿着物品时保存也会保留上一次完整事务，避免退出造成物品丢失。打开时世界和营业计时暂停；支持键盘焦点、四种语言及重新绑定后的互动键。

每个箱子和背包的格子顺序随存档保存，跨场景、跨日和重启保留。移动箱子保留内容，取空后才能收回。地图会显示已摆放箱子。旧版数量库存自动装入格子，超出容量的物品保存在旧版溢出库存，可在腾出空格后领取。

`inventory_items.gd` 统一槽位、堆叠、原子增减与旧版迁移，保留游戏数量字段作为同步镜像；`grid_session.gd` 处理拿取、拆分、交换、快速移动及关闭回收；`chest_ui.gd` 与 `inventory_slot.gd` 处理原生输入和共享格子界面，完成转移后的状态随游戏时钟每六小时自动保存，或随手动、退出保存写入。存档校验同时检查槽位长度、数量、物品标识及工具唯一性。

```powershell
python Scenes/Storage/run_verification.py headless
python Scenes/Storage/run_verification.py capture
python Scenes/Storage/run_verification.py restart
```

首次通过命令行运行新增素材前可执行 `python Scenes/Storage/run_verification.py import`；正常从 Godot 编辑器打开项目会自动导入 PNG。木箱使用 [karsiori 的 CC0 像素素材](https://karsiori.itch.io/pixel-art-chest-pack-animated)中 Wooden Chest 1，原生48×36，原图字节、透明度和画布完整保留。素材、原包、授权与哈希清单位于 `Art/Props/KarsioriChest/`。房间、摆放预览和地图共用闭合贴图；箱子在储物界面打开和关闭时播放原包开合帧，世界暂停期间仍更新，碰撞、存档和物品存取规则保持原样。旧SVG占位图保留。

`verify_grid.gd` 使用独立设置和存档目录，覆盖真实左右键、拖动、Shift 转移、交换、工具等级、满格保护、迁移、异常数据、关闭回收、手动保存及两个新进程之间的持久化，并用 1,000 次混合操作验证数量守恒。截图和日志保存在 `Verification/`。
