# 魔女帽鼠标

全局硬件指针用于启动页、主菜单、游戏场景和弹窗。保留标准的左上箭头轮廓，右下尾部连接小魔女帽。普通箭头与地图地点的手形状态均使用这一美术，其他系统专用光标保留其原有含义。

- 箭头采用奶油色填充与深紫色描边；尾部的小帽子在 `build_cursor.py` 中逐像素绘制，沿用项目原创 `Scenes/Save/saving_indicator.gd` 的紫色与金色配色，并增加奶油色外边，兼顾深色和浅色背景。
- `witch_hat_native.png`：32×32 原生 RGBA 像素稿。
- `witch_hat.png`：最近邻整数放大的 64×64 硬件指针，透明度仅为 0/255。
- 点击热点为 `(4, 4)`，位于左上箭头尖端。魔女帽是尾部装饰。指针尺寸不受 640×360 游戏画布缩放影响。
- `preview.png`：深紫、草地和暖色界面的美术预览，第一行是实际尺寸，第二行是放大细节。
- `Scenes/UI/mouse_cursor.gd` 作为 `WitchCursor` 自动加载项设置原生指针，无逐帧跟随节点，不接管鼠标事件。暂停、弹窗与场景切换不会移除指针。

重新导出：`python Art/UI/WitchCursor/build_cursor.py`，需要 Pillow。像素源位于导出脚本，配色取自现有保存图标，不依赖图像生成服务。

本次没有添加玩家可见文字，也没有变更输入映射或焦点导航，因此无需新增本地化条目。

验证：箭头加帽子尾部的新版素材通过 Godot 导入；图形窗口中的既有菜单检查 32 项、HUD 检查 52 项全部通过，覆盖鼠标按钮、滑块、背包、设置弹窗和暂停。启动验证前设置独立配置和存档路径。新版日志保存于 `output/witch_cursor/arrow_menu.log` 和 `output/witch_cursor/arrow_hud.log`。退出时清除两个硬件光标状态，避免 Input 在渲染服务器销毁后继续持有纹理。
