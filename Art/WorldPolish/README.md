# 探索区域美术与布局

六个区域的实际场景、暂停地图、碰撞、资源位置及脚步材质共用同一份布局，避免地图能看见的道路在场景里无法通过。

| 区域 | 构图 |
| --- | --- |
| grove | 林间分岔、倒木与采集支路 |
| quarry | 采石平台、木梁入口与石堆 |
| marsh | 水渠分隔的湿地、可通行木桥 |
| ruins | 断柱、石台与遗迹小径 |
| ridge | 山脊台阶、栏杆与折线路径 |
| observatory | 石质星盘、灯柱与观测空地 |

生成工具：`python Art/WorldPolish/tools/build_regions.py`，依赖 Pillow。输出仅在本目录，包含每区布局 JSON、原生 Aseprite 地面/地图预览、PNG 预览和总览图。运行前后核对 `MyArt/` 全部文件 SHA-256；不会写入或清理原稿目录。

草地、泥路和场景物件取自项目现有 `Art/Environment/Hearthwood/`，按原像素、透明度和原尺寸组合；台阶、木梁、石柱、星盘等补充地标在本工具中绘制。未使用参考游戏中的图像、人物或地图。地面为 40×23 个 16 像素格；实际可见画面 640×360。资源树、矿石及其采空状态由场景和地图共同动态绘制。

`Scenes/Campaign/region_layout.gd` 负责加载和缓存。修改布局应重新生成全部区域，再运行 `Scenes/Gameplay/run_project_polish.py`，核对入口、出口、六处采集点和三处资源交互位置可达。
