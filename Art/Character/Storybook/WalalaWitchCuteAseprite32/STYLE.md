# 可爱版人物风格记录

用途为当前 Godot 地图主角，优先沿用项目已验证的 32×32 合同，而非技能中其他项目的 32×48 默认规格。四方向顺序 down/up/right/left，共 152 帧、28 个 Forward 标签、9 图层；脚底锚点 (16,32)，精灵表 256×608，8 列×19 行，Alpha 0/255。待机、行走、奔跑、施法、钓鱼的范围和时长不变。

视觉参考实际查看了项目内《东方夜雀食堂》的“主角的家（加上主角）”及《多洛可小镇》的“工具栏与时间”截图。前者用于观察圆脸、大眼与短身比例，后者用于观察缩小后仍能辨识的轮廓和紧凑色块。没有拷贝参考像素、衣服、人物或标志。

同规格对照为原主角，以及 NPC32 的梅布尔 mori（辫子与围裙）、露辛达 yingluo（帽子与手提灯）、blue_blonde（简洁短发）。对照图展示 4× 像素与主角的 1× 实际尺寸；NPC 没有改动。

保留三个特征：紫色弯尖帽与金色月牙、银白短发与奶油领口、原有动作节奏与脚底位置。设计差异为更大的圆脸、2×3 高光眼睛和腮红、上提帽檐及玫瑰色领口。帽檐约24像素、短发约16像素，头发覆盖肩部两侧；身体仍保持原版的短斗篷和细腿比例。

轮廓采用暖紫 #3b2c47，布料 #8a63a0 / #ab86bd / #cbaad9，头发 #b0abc8 / #e2dffa / #fff6ee，腮红 #e89cad。每种材质约3个明暗色块，左上光、整像素边缘；23个可见颜色。没有缩放重采样源像素或混合像素密度。挎包与月饰固定于角色左侧：正面右侧、背面左侧、左侧面可见、右侧面被遮挡，侧面不是直接复制镜像配饰。

动作沿用已验证的脚、手、法杖与特效坐标。行走、奔跑循环在同一相位序列中采样，不添加重复末帧；`loop-review.png` 额外显示首帧仅供对照，不进入精灵表。`loop-review.json` 保存相邻帧及尾首变化量；1像素/2像素起伏为原有行走/奔跑节奏。所有运行时帧通过源像素比对，设置、存档和日志使用独立测试目录。
