# 《明天晚点开门》游戏接入

开场43句、十章主线393句已接入 Godot 项目。原稿仍保留在本目录；运行数据编译到 `Scenes/Campaign/content.gd`，导出游戏不依赖外置对白文本。

2026年10月20日口语调整：开场43句全部重写，十章主线另改106句；五段分镜文案、十章任务简介和三位居民中9条相关文本同步调整。人物直接说明来意、困难和决定，减少半句话、抽象比喻和格言式收尾。开场先聊船程、住处、开店与吃饭，租约按人物关心的问题逐项回答。英文、日文与繁体同步更新。

参考资料为[《多洛可小镇》初入小镇流程](https://www.bilibili.com/video/BV1aaMg66Exf/)和[《东方夜雀食堂》序章流程](https://www.bilibili.com/video/BV164596sEsT/)中可访问的开场片段；未取得完整对白转录。这里采用日常话题和直接回应的写法，游戏正文为原创对白。

新存档播放30秒的新版分镜，再依次进入码头、农场门前、食堂。动画可以略过；开场对白保留。签约场景开放免租试营，随后恢复自由活动。

主线由萤萝与四季手记推进，使用实际的上菜、收获、鱼获、山径调查、零件和餐厅等级记录。第八章交付铁锭4、旧械零件6、月晶4，各项分别检查并扣除；其他章节使用累计记录。完整章节对白沿用角色头像、翻页和回看，已完成章节可以回顾。

开场每段结束、章节交付、章节对白结束分别保存。中断后从当前段或本章对白开头恢复；不重复发奖或扣料。新版结束后继续自由经营。

已有旧存档从新版第一章开始；金币、库存、农田、工具、好感、支线及已解锁区域保留，正在游玩的旧档跳过新开场。本次验证使用独立测试存档，没有读取或改写玩家正式进度。

剧情中的合单、商队退款、月租、轮值和固定船期作为对白事件接入；没有新增独立货运、预约订单、自动扣租或轮班模拟系统。章节中的春夏秋冬表达叙事顺序，不强制等待游戏日历到某一天。

英文、日文对白按场景行号保存在 `translations_en_ja.txt`；繁体对应保存在 `translations_zh_TW.json`。四语言词库同步到 `Localization/messages.tsv`。与新设定冲突的奥萝匿名信、星芒记忆供能及余烬事故解释已经替换。

开发验证：

```powershell
python -B Scenes/Campaign/build_content.py
python -B Localization/build_catalog.py
python -B Scenes/Campaign/run_rebuilt_story_verification.py
python -B Scenes/Campaign/run_rebuilt_story_verification.py capture
```

测试日志、检查结果和实际截图位于 `output/story_rebuild_integration/`；验证包含所有章节与四语言对白尺寸、开场输入、实际场景切换、旧档迁移、修缮扣料、剧情续播及重复领奖保护。美术原稿目录 `MyArt/` 保持只读。
