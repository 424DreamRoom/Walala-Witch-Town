# 月芽农场

玩家的小屋已从小镇搬到独立的 `farm.tscn` 场景。沿小镇西侧石路走到左边缘 `(8,364)` 自动进入农场；农场东侧 `(952,364)` 通回小镇。接缝两端都是52像素宽的石路，道路画到图像之外，农场落点 `(918,364)` 在路中央，内侧自然接回土路。北侧小屋门口 27 像素内按交互键（默认 E）进入住宅，室内底部出口也需交互才会回到门前第一块石阶 `(270,258)`，角色朝下；旧存档出门也使用此落点。农场为 960×720，镜头、角色移动、碰撞、天气、昼夜、环境动画和脚步声沿用现有系统。

## 种植

- 房屋南面有 12×8 格田地，每格 32 像素，共 96 格。面向一格田地，浅色方框表示当前目标，近距离文字只显示土地或作物状态。
- 反复按互动键（默认 E）依次锄地、播种香草、浇水；翻地与浇水共用开局法杖。操作间隔 0.25 秒，长按不会重复消耗。
- 初始提供 12 颗种子，法杖储水容量 24。到水井南面或池塘南岸按 E 补满，不消耗金币。下雨会打湿所有已开垦泥土（含空地和成熟作物），不消耗法杖储水；白天、夜间、玩家在别的地图或室内均生效。雨中新增的耕地也会自动湿润。
- 湿土在雨停、播种及收获后保留湿润，当天无需再次浇水。进入次日时，湿土上的未成熟作物增长一天，随后土壤恢复干燥；若仍下雨则再次湿润。香草累计 3 天成熟。干土上的作物暂停生长，作物不会消失，土地也不会每日重置。
- 成熟后按 E 收获香草 1 份与种子 2 颗，田地保留已翻土状态。香草进入现有 12 格食材背包，可在餐厅加工成香草料或在杂货店卖出。满背包时作物保留，腾出空间后可再收。
- 杂货店新增香草种子 4 颗 / 2 金，以及售出香草 1 份 / 3 金。
- 耕种和补水在白天进行；原有白天结束自动回餐厅营业的循环保留，夜间仍可回农场和家。

农田状态、种子、水量及房屋返回落点随存档保存。旧存档不含农场数据时补上初始种子和水量；旧版保存于家中的进度仍可加载，离开后抵达农场。

## 文件与验证

`farm.gd` 负责地图、交互目标和田地显示；种植、每日生长和持久化在 `Scenes/Gameplay/loop_state.gd` 中统一处理，切换场景不会创建新的库存副本。

```powershell
python Art/Environment/Hearthwood/tools/build_farm.py
python Scenes/Gameplay/run_verification.py farm
python Scenes/Gameplay/run_verification.py farm_capture
```

生成器复用现有 `shop_0.png`、装饰和 Hearthwood 调色板；`farm_ground.png` 为地面，`farm_overview.png` 为美术总览，地图布局为 `farm_layout.json`。导出时须将该 JSON 与其他地图 JSON 一起包含。

集成验证覆盖真实行走的镇口、房门与返回、田地和水源可达、E 种植收获、水源碰撞、雨水、跨天生长、背包容量、交易、存档写入与恢复、旧存档迁移、非法数据拒绝。实机截图位于 `Verification/`；日志为 `output/loop_farm*.log`。当前先提供一种可用于料理的香草，没有季节限制、枯萎或自动洒水器。
